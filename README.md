# Homebrew tap for QLStephenSwift

This repository is a personal Homebrew tap for **QLStephenSwift**.

## What is QLStephenSwift?

QLStephenSwift is a macOS app related to Quick Look support. It is distributed here as a signed and notarized DMG release and can be installed with Homebrew Cask.

## Install

Add this tap:

```sh
brew tap MyCometG3/qlstephenswift
```

Install the app:

```sh
brew install --cask qlstephenswift
```

## Cask details

- Cask name: `qlstephenswift`
- App bundle: `QLStephenSwift.app`
- Release source: GitHub Releases
- Tap repository: `MyCometG3/homebrew-qlstephenswift`

## Notes

- Releases are expected to be signed and notarized.
- The DMG should contain the app bundle with a stable name.
- If macOS blocks the app the first time, allow it in Security & Privacy and try again.
